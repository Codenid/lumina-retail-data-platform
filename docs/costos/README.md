# Visor de costos GCP

Abre [`index.html`](index.html) para consultar el costo mensual base, la proyección conservadora y el escenario de máxima demanda.

El visor muestra grupos de servicios, capacidad, unidad de cobro, costo actual y costo proyectado. Selecciona un grupo y abre `Ver detalle` para revisar el supuesto técnico.

Escenarios:

- Base: consumo nominal.
- Conservador: base × 1.8.
- Máxima demanda: base × 2.5.

La web es un modelo de planificación; las tarifas y consumos deben contrastarse con Google Cloud Pricing Calculator antes de contratar capacidad.
