### Anticipar la demanda. Optimizar el inventario. Acelerar la entrega.

[Informe completo](docs/report/Lumina_Retail_Informe.pdf) · [Informe de implementación](implementation/docs/informe-tecnico/informe/informe-tecnico-implementacion-gcp.pdf) · [Web de costos](docs/costos/index.html) · [Arquitectura](#arquitectura) · [Implementación](#implementación) · [Documentación](#documentación)

## Resumen ejecutivo

El proyecto integra ventas, pedidos, inventario, logística, clientes y
telemetría de RetailSmart Global para generar indicadores, alertas,
predicciones y recomendaciones operativas.

La solución prioriza un recorrido completo de inventario y pedidos, con una
evolución gradual hacia nuevos casos de uso. Los sistemas operacionales
mantienen la autoridad sobre reservas, pagos y despachos.
